# INIAD-AIO v1.0 Demo Guide

Date: 2026-07-08

## 目的

v1.0 は、発表で安定して見せるためのローカル学習資料デモです。

- COT101 / SEM101 / COT105 の課題候補を一覧で確認する
- MOOCs-Collect が保存したPDFを AIO 側で一覧化する
- 文字PDFではPDFのテキストレイヤーを `data/local/text_cache/` に保存する
- 画像・描画ベースPDFでは講義回、講義タイトル、PDFタイトルで検索する
- ローカル検索APIと最小UIでPDF資料を検索し、PDFを開く
- 検索結果からPDFをブラウザで開く

## 事前確認

```powershell
git status --short --branch
.\.venv\Scripts\python.exe -m unittest discover -s tests
```

`data/local/` はローカル実データ用で、コミットしません。

## Resource Index 生成

MOOCs-Collect のPDF保存先を指定して、resource index と text cache を生成します。

```powershell
.\.venv\Scripts\python.exe scripts\build_local_resource_index.py `
  --root "C:\Users\iniad\Documents\moocs-collect\2026\情報連携学概論 I" `
  --output data/local/resource_index.json `
  --extract-text `
  --text-cache-dir data/local/text_cache
```

確認すること:

- `data/local/resource_index.json` が生成される
- `resources[].text_available` が文字PDFで `true` になる
- `resources[].text_cache_path` が入る
- `data/local/text_cache/` にJSON cacheが生成される
- 画像PDFや読めないPDFは warnings に入り、処理全体は止まらない
- `summary.extracted_count` が `0` でも、講義回・講義タイトル・PDFタイトル検索は利用できる

- `title`
- `course_title`
- `lecture_key`
- `lecture_title`
- `snippet`
- `page_number`
- `open_url`

実PDFが画像・描画ベースの場合、`text_available` は `false` のままになることがあります。その場合のv1.0デモは、本文検索ではなく `course_title`、`lecture_key`、`lecture_title`、`title` の検索とPDFを開く導線を見せます。

- `git status` に `data/local/` が出ていない
- 全テストが通っている
- resource index が実データで生成済み
- 検索語を3つ用意している
- PDFを開く導線を1回確認済み
- 課題一覧の「開く」と status 変更を1回確認済み

## v1.0でできないこと

- OCR
- Embedding検索
- MCP連携
- 本格Ontology
- Google Slides DOM / SVG 由来の本文cache化
- Slack連携
- 認証
- DB大改修

これらは v1.1 以降の候補として扱います。

## v1.1 experimental: MCP / Ontology / Context Card / Embedding

v1.0 発表版の安定デモはこの文書の上記手順のまま維持します。
`feature/v1.1-adventure-mcp-ontology` では、通常 Web UI を壊さない別枠の実験として以下を追加しています。

- MCP server: `python -m backend.app.mcp.aio_server --base-url http://127.0.0.1:8000`
- MCP tools: `list_tasks`, `get_task_evidence`, `list_local_resources`, `search_local_resources`, `get_local_resource`
- LocalResource ontology: `resource_kind`, `entity_type`, `source_kind`
- Context Card: `card_text` を `resource_index.json` と API response に付与
- Search mode: `/api/local/resources/search?q=...&mode=keyword|semantic|hybrid`
- Embedding fallback: 外部 API キー不要の `local-hashed-bow-v1`
- Vector cache: `python scripts/build_local_resource_vector_cache.py --index data/local/resource_index.json --output data/local/resource_vectors.json`

v1.1 実験を見る場合の最小手順:

```powershell
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
.\.venv\Scripts\python.exe -m backend.app.mcp.aio_server --base-url http://127.0.0.1:8000
```

API 確認:

```powershell
Invoke-RestMethod "http://127.0.0.1:8000/api/local/resources/search?q=security&mode=semantic&limit=5"
Invoke-RestMethod "http://127.0.0.1:8000/api/local/resources/search?q=security&mode=hybrid&limit=5"
```

注意:

- semantic は本格 embedding ではなく deterministic fallback です。
- 実データ `data/local/` と vector cache はコミットしません。
- MCP server が落ちても FastAPI / Web UI は通常どおり起動できます。
