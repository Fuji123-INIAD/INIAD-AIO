# INIAD-AIO v0.3 Implementation Tasks

## 目的

v0.3 の実装順序を定義する。

v0.3 は、v0.2 のサーバー型検索プロトタイプを、ローカルアプリ + MCP 構成へ移行する。

最優先は以下。

1. 溜まっている課題一覧
2. 講義・課題・資料ページへのURL提供
3. AIから曖昧な質問で講義内容を検索できるMCP search
4. AIとの会話から講義・課題・資料・PDFを開ける open_item

---

状態: 完了

完了済み:

* v0.2タグ作成
* v0.3ブランチ作成
* v0.3全体設計
* migration map
* local DB schema

## Phase 1: ローカルDB基盤

目的:

PostgreSQL必須構成から、ローカルSQLite中心の構成へ移行する。

作業:

* `backend/app/` ディレクトリを作成
* `backend/app/db/` を作成
* v0.3用SQLite schemaを作成
* DB初期化処理を作成
* `app_settings` を読み書きできるようにする
* `courses`, `lectures`, `pages`, `tasks`, `user_task_status` を作成
* 既存 `backend/database.py` は参考にするが、そのまま流用しない

成果物:

* `backend/app/db/schema.sql`
* `backend/app/db/local_db.py`

完了条件:

* ローカルSQLiteファイルを作成できる
* schemaを適用できる
* `app_settings` に値を保存・取得できる

---

## Phase 2: 課題一覧API

目的:

v0.3の最優先機能である「溜まっている課題一覧」を実装する。

表示条件:

* セットアップ時に選択された科目
* 提出期限が未来
* ユーザー側の提出済チェックが押されていない
* ignored ではない

期限不明の課題は別枠にする。

作業:

* `tasks` を取得するクエリを作成
* `user_task_status` を反映する
* `done` / `ignored` の更新APIを作成
* 課題ページURLを必ず返す
* 期限不明課題を別枠で返す

API案:

* `GET /api/local/tasks`
* `PATCH /api/local/tasks/{task_id}/status`

成果物:

* `backend/app/core/tasks/task_service.py`
* `backend/app/api/tasks.py`

完了条件:

* 未完了課題一覧をJSONで取得できる
* 課題をdoneにできる
* 課題をignoredにできる
* 課題URLが返る

成果物:

* `backend/app/core/moocs_sync/sync_service.py`
* `backend/app/core/moocs_sync/importer.py`
* `backend/app/api/sync.py`

完了条件:

* 1年生対象科目のMOOCs情報をローカルDBへ同期できる
* 課題一覧APIが同期済みデータを表示できる

## Phase 4: セットアップ時の科目選択

* `PATCH /api/local/courses/{course_id}/enabled`

成果物:

* `backend/app/core/settings/course_settings.py`
* `backend/app/api/courses.py`

完了条件:

* 対象科目を有効/無効にできる
* 課題一覧が有効科目だけを表示する

## Phase 5: MOOCs-Collect PDF ingest

目的:

MOOCs-Collectが保存したPDFをAIO側に取り込む。

方針:

MOOCs-Collectはdownloaderとして扱う。AIOはPDFフォルダと必要に応じてSQLiteをread-onlyで読む。

作業:

* MOOCs-Collect保存先を設定できるようにする
* PDFフォルダを走査する
* `slide_files` にPDFを登録する
* 可能ならMOOCs-Collectの `db.sqlite` から科目・講義・ページ情報を補完する
* ファイルサイズ・mtimeを記録する
* hashは初期実装では後回しでもよい

成果物:

* `backend/app/core/moocs_collect/locator.py`
* `backend/app/core/moocs_collect/ingest.py`
* `backend/app/core/moocs_collect/adapter.py`

完了条件:

* MOOCs-CollectのPDF一覧をAIO DBに登録できる
* 科目・講義とPDFを可能な範囲で対応付けできる

---

## Phase 6: PDF本文抽出

目的:

PDFスライドを検索対象にする。

方針:

v0.3ではOCR必須化はしない。文字PDFだけ本文抽出する。

作業:

* PyMuPDF等でPDF本文を抽出する
* ページ単位または細かいチャンク単位で `slide_chunks` に保存する
* 文字が取れないPDFは「本文なし」として扱う
* 初回同期時に時間がかかる場合はUIで断りを表示する

成果物:

* `backend/app/core/pdf/extract_text.py`
* `backend/app/core/pdf/chunking.py`

完了条件:

* PDFから本文を抽出できる
* `slide_chunks` に保存できる
* どのPDFの何ページ由来か追跡できる

---
