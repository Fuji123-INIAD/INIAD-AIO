# INIAD-AIO v0.3 Local DB Schema

## 目的

v0.3 のローカルアプリ + MCP 構成で利用するローカルDBスキーマを定義する。

DBはローカル利用を前提とし、クラウド共有や複数ユーザー同時利用は前提にしない。

## 方針

- SQLite を第一候補とする
- PostgreSQL 必須構成は廃止する
- MOOCs由来データとユーザー状態データを分離する
- MOOCs-Collect 由来データは read-only で取り込み、AIO側で独自IDを持つ
- 検索結果やAI回答は保存しない
- PDF本文チャンクは保存する

## tables

### app_settings

| column | type | note |
|---|---|---|
| key | TEXT PRIMARY KEY | 設定キー |
| value_json | TEXT NOT NULL | JSON文字列 |

## 課題一覧クエリ

表示対象:

- user_course_settings.enabled = 1
- deadline_at が未来
- user_task_status.status が done ではない
- user_task_status.status が ignored ではない

期限不明の課題は別枠で表示する。
