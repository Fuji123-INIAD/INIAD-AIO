# INIAD-AIO v0.3 Local MCP Design

## 目的

INIAD-AIO v0.3 は、INIAD 1年生が MOOCs 上の講義・課題・資料情報をローカルに同期し、普段使う AI から MCP 経由で参照できるようにするためのローカル情報アクセス基盤である。

v0.2 のサーバー型検索デモから、v0.3 ではローカルアプリ + MCP 方式へ移行する。

## 主機能

1. 1年生 MOOCs 全科目の情報同期
2. セットアップ時の対象科目選択
3. 溜まっている課題一覧
4. MOOCs-Collect が保存した講義スライド PDF の取り込み
5. PDF本文抽出
6. Meilisearch + rerank による横断検索
7. MCP 経由の search
8. MCP 経由の open_item
9. 講義ページ・課題ページ・資料ページへのURL提供
10. MCP設定支援

## やらないこと

- クラウドサーバー運用
- Cloudflare Tunnel 前提の公開デモ
- 複数ユーザー共有DB
- AIO内蔵AIチャット
- 高度な第二の脳機能
- 行動ログ管理
- OCR必須化
- MOOCs-Collect の内部 Tantivy インデックス直接利用
- MOOCs-Collect の SQLite / store.json 書き換え

## v0.2 から流用するもの

- MOOCs のスライド以外の情報取得処理
- Meilisearch 登録処理
- rerank 処理
- 検索API内部ロジック
- 既存DB設計の一部
- FastAPI の一部エンドポイント実装

## 作り替えるもの

- サーバー公開前提の backend
- ローカルアプリ用の同期処理
- ローカルDB
- MCP tools
- 課題一覧UI
- MOOCs-Collect PDF ingest adapter
- MCP設定出力UI

## MOOCs-Collect 連携方針

MOOCs-Collect は downloader として扱う。

AIO は以下を read-only で参照する。

- PDF ファイル
- 保存フォルダ
- 必要に応じて db.sqlite
- 必要に応じて store.json

AIO 側で独立して実装するもの。

- PDFカタログ
- 安定ID
- PDF本文抽出
- 検索インデックス
- MCP
- 更新検知

## 課題一覧仕様

表示対象は以下。

- セットアップ時に選択された科目
- 提出期限が未来
- ユーザー側の提出済チェックが押されていない
- ignored ではない

期限不明の課題は別枠で表示する。

ステータスは以下。

- open
- done
- ignored

## MCP tools

### search

曖昧な質問から、講義・課題・資料・スライド本文を横断検索する。

### open_item

search や list_tasks の結果を開く。

対象。

- lecture: MOOCs講義ページ
- task: MOOCs課題ページ
- material: MOOCs資料ページ
- slide_page: ローカルPDFの該当ページ

### list_tasks

溜まっている課題一覧を返す。

## URL方針

全エンティティに可能な限りURLを持たせる。

- course_url
- lecture_url
- task_url
- material_url
- local_pdf_path
- page_number

検索結果やMCP応答には、AIがユーザーへ提示できるURLを必ず含める。
