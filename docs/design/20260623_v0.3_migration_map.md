# INIAD-AIO v0.3 Migration Map

## 目的

v0.2 のサーバー型プロトタイプから、v0.3 のローカルアプリ + MCP 構成へ移行するために、既存ファイルの扱いを整理する。

## 現行構成

### backend/main.py

FastAPI アプリ本体。現状では以下が集中している。

- API定義
- MOOCs情報 import
- Meilisearch 登録
- 検索
- ask
- PlaywrightによるMOOCsページ取得
- PostgreSQL接続

方針: 分解対象。v0.3ではそのまま維持せず、機能ごとに core / api / mcp へ分離する。

### backend/moocs_probe.py

MOOCs取得・調査系。

方針: v0.3の local sync に流用候補。

### backend/search_backend.py

検索処理。

方針: Meilisearch + rerank の中核として流用候補。

### backend/ai_module.py

AI回答・rerank関連。

方針: rerank処理は流用候補。AIO内蔵AIチャット用途はv0.3では縮小。

### backend/database.py

DB初期化・接続。

方針: ローカルDB向けに作り替え。

### backend/schema.sql

現行DBスキーマ。

方針: v0.3ローカルDBスキーマの参考にする。

## v0.3で残す機能

- MOOCsスライド以外の情報取得
- 課題情報取得
- 講義情報取得
- 資料情報取得
- Meilisearch登録
- rerank
- 検索結果整形

## v0.3で削る・縮小する機能

- クラウドサーバー前提API
- Cloudflare Tunnel前提
- 複数ユーザー共有DB前提
- AIO内蔵 ask API
- PostgreSQL必須構成
- Docker前提運用

## v0.3で新規追加する機能

- ローカルDB
- 課題一覧 status
- 選択科目設定
- MOOCs-Collect PDF ingest
- PDF本文抽出
- slide_page index
- MCP search
- MCP open_item
- MCP list_tasks
- MCP設定支援
